## 1. 项目简介与产品定位

### 1.1 项目简介

「知路」是一款面向学生与自学者的**个性化学习路线规划工具**。产品核心解决以下痛点：

- **不知道学什么**：用户想学习一个新领域，但面对海量知识不知从何入手
- **不知道该先学什么**：缺乏知识模块的依赖关系和先后顺序指导
- **不知道怎么学**：没有根据个人时间、基础和偏好定制学习节奏
- **不知道学没学会**：缺乏即时的练习巩固和自我检测机制

用户只需在首页填写身份信息、技能爱好和学习想法，系统即可**自动生成一条带有知识依赖排序、分阶段推进、匹配个人节奏的完整学习路线**，并配套练习巩固系统，让用户"学有方向、练有反馈"。

### 1.2 产品定位

| 维度 | 说明 |
|------|------|
| **目标用户** | 在校学生（高中/大学/研究生）、职场新人、求职转型者、自由职业者——所有"想从零学点什么但不知从何开始"的人群 |
| **核心价值** | "让零基础的人也能获得一条清晰、可执行、适合自己的学习路线" |
| **产品形态** | Web 应用（单文件 HTML），浏览器即开即用，无需安装 |
| **当前阶段** | MVP 原型阶段，预置 3 个知识领域（Python 编程、机器学习、英语提升），支持本地数据持久化 |
| **差异化** | 区别于普通网课平台的"给所有人同一份课表"，知路基于用户画像做**个性化路线生成**，且整个学习过程（规划→学习→练习→记录）在一个工具内闭环完成 |

## 2. 启动方式与环境变量说明

### 2.1 技术特性

本项目为**纯前端单文件 HTML 应用**，无 Node.js 后端、无数据库、无 API 依赖。

- **数据存储**：`localStorage`（浏览器本地持久化）
- **图表能力**：Chart.js（CDN 引入）
- **字体资源**：Google Fonts（CDN 引入）

### 2.2 环境变量说明

本项目**无需任何环境变量**。所有依赖均为公共 CDN 资源，无需配置密钥或私有服务。

| 变量名 | 是否必需 | 默认值 | 说明 |
|--------|---------|--------|------|
| 无 | — | — | 本项目为纯静态页面，不涉及环境变量 |

### 2.3 本地启动方式

**方式一：直接浏览器打开（最简）**

```bash
# 双击打开，或将文件拖到浏览器中
zhilu.html
```

**方式二：本地静态服务器（推荐，用于开发调试）**

```bash
# 使用 Python 内置服务器
cd 项目目录
python -m http.server 8080

# 或使用 Node.js 的 npx
npx serve .

# 或使用 VS Code Live Server 插件
```

浏览器访问 `http://localhost:8080/zhilu.html` 即可。

### 2.4 线上部署方式

**方式一：GitHub Pages（推荐，免费且稳定）**

1. 新建 GitHub 仓库，上传 `zhilu.html` 到仓库根目录
2. 进入仓库 Settings → Pages → Source 选择 Deploy from a branch，Branch 选 `main`
3. 等待 1-2 分钟，获得 `https://yourname.github.io/repo-name/zhilu.html`

**方式二：Vercel/Netlify（拖拽部署）**

1. 注册 Vercel/Netlify 账号
2. 将 `zhilu.html` 文件直接拖入平台部署界面
3. 自动获得线上访问链接

**方式三：腾讯云 COS / 阿里云 OSS**

1. 购买对象存储服务
2. 上传 `zhilu.html` 文件
3. 开启静态网站托管，绑定域名即可获得线上地址

## 3. 核心使用流程与 AI（规则引擎）介入环节说明

### 3.1 整体流程图

```
首页收集信息
    ↓
选科页面（推荐 + 手动选）
    ↓
自检水平（跳过已掌握模块）
    ↓
时间与方式偏好
    ↓
目标设定
    ↓
生成路线
    ↓
主应用（仪表盘/路线/练习/数据）
```

### 3.2 核心使用流程详解

#### Step 1：首页 —— 用户画像采集

用户进入应用后，首先看到个人信息收集页。需完成三项输入：

- **身份选择**（必选）：从 10 种身份（高中生、大学生、研究生、在职-技术岗、在职-非技术、自由职业者、求职转型者、创业者、退休人士、其他）中选择一项
- **技能与爱好**（多选，可跳过）：从 28 个标签中选择已掌握或感兴趣的领域
- **想法框**（可选，最多 500 字）：自由描述"想学什么、为什么学、期望达到什么目标"

> **AI/规则引擎介入点**：此步骤仅做数据采集，无算法介入。采集的数据将作为后续推荐的输入特征。

#### Step 2：选科页面 —— 个性化科目推荐

进入选科页面后，系统根据 Step 1 采集的用户画像，运行**多维度匹配规则引擎**，为三个预置科目（Python 编程、机器学习、英语提升）计算匹配分数。

**匹配算法（规则引擎）说明：**

| 匹配维度 | 权重 | 计算方式 |
|---------|------|---------|
| **技能匹配** | 最高 50 分 | 用户已选技能与科目关联技能重叠，每重叠一项 +18 分 |
| **身份匹配** | 25 分 | 用户身份在科目关联身份列表中即 +25 分 |
| **关键词匹配** | 最高 25 分 | 想法框文本中出现科目关键词，每出现一个 +10 分 |

**排序与展示逻辑**：按总分从高到低排序，超过 25 分（即除身份基线外有额外匹配）的科目在顶部以「推荐卡片」形式展示，附匹配理由标签（如"匹配技能: 编程开发、数据分析""想法中提及: python、爬虫"）。用户可一键选择推荐科目，也可在下方手动选择任意科目。

> **AI/规则引擎介入点**：此为当前版本的核心推荐逻辑，基于硬编码规则而非 LLM。规则引擎根据多维度特征加权打分，实现"千人千面"的科目推荐。

#### Step 3：自检水平 —— 知识模块评级

针对所选科目的全部知识模块（Python 9 模块、机器学习 10 模块、英语 9 模块），用户逐一自评当前水平：

- 不了解（0）/ 略知一二（1）/ 基本掌握（2）/ 完全掌握（3）

> **AI/规则引擎介入点**：系统标记"完全掌握（3）"的模块为"已跳过"，后续生成路线时自动排除，减少重复学习。

#### Step 4：时间与方式偏好 —— 节奏定制

用户配置：
- 每天可投入的学习时间（15 分钟 ~ 4 小时，滑块调节）
- 偏好学习方式（视频课程 / 图文阅读 / 动手实操 / 混合方式）

> **AI/规则引擎介入点**：根据时间投入调整每个模块的建议天数（时间少则延长、时间多则缩短），并根据方式偏好重排每个模块的推荐学习方法顺序。

#### Step 5：目标设定 —— 深度选择

用户选择学习目标：快速入门（路线天数 ×0.75）/ 均衡学习（原样）/ 深度掌握（路线天数 ×1.25），并可设定期望完成日期。

#### Step 6：路线生成 —— 依赖排序与可视化

系统生成最终学习路线：

1. **模块过滤**：排除自检中"完全掌握"的模块
2. **时长调整**：根据时间偏好和目标深度调整各模块建议天数
3. **阶段分组**：按 foundation（基础）/ advanced（进阶）/ practice（实战）三阶段分组
4. **路线可视化**：以竖向时间线展示所有模块，标注阶段标签、知识点数量、推荐方式、当前状态

> **AI/规则引擎介入点**：路线生成的核心逻辑由规则引擎完成，基于预设的知识依赖关系和用户画像参数计算得出。

#### Step 7：学习与练习 —— 即时检测

用户在学习路线页面点击模块进入练习。每个模块配套 3 道选择题，答完后即时判分并显示解析。60 分以上标记为"已完成"，解锁下一模块。

> **AI/规则引擎介入点**：当前版本的练习题目和解析为硬编码内容，非动态生成。未来版本可接入 LLM 实现自适应出题和智能解析。

#### Step 8：学习数据 —— 行为自动记录

系统自动记录 7 类学习行为：完善信息、生成路线、开始学习、开始练习、通过练习、练习未通过、全部完成。数据以表格和折线图形式展示，用户可查看成绩趋势、模块进度、活跃天数等统计。

> **AI/规则引擎介入点**：此处为数据记录和可视化，无算法生成内容。

## 4. 技术栈清单

| 分类 | 技术/工具 | 版本/来源 | 用途 |
|------|----------|----------|------|
| **前端框架** | 原生 HTML5 + CSS3 + JavaScript | ES5（兼容旧浏览器） | 构建单页应用，无框架依赖，降低部署门槛 |
| **样式方案** | 原生 CSS（CSS Variables） | — | 主题色管理、响应式布局、暗色侧边栏 |
| **数据持久化** | localStorage | Web API | 用户画像、学习进度、练习记录、活动日志本地存储 |
| **图表库** | Chart.js | v4.4.0 (CDN) | 学习数据页面的成绩趋势折线图 |
| **字体资源** | Inter (Google Fonts) | CDN | 界面字体，提升现代感 |
| **存储迁移** | 原生 JS JSON 解析 | — | v1 旧数据自动迁移到 v2 数据结构 |
| **推荐引擎** | 原生 JS 规则引擎 | — | 基于身份×技能×关键词的多维度加权匹配 |
| **构建工具** | 无需构建工具 | — | 单文件 HTML，直接部署 |
| **部署平台** | GitHub Pages / Vercel / Netlify | — | 静态文件托管 |

### 4.1 架构特点

- **单文件架构**：所有 HTML/CSS/JS 内联在一个 `.html` 文件中，无打包、无依赖安装
- **零后端**：无服务器、无数据库、无 API 密钥
- **零环境变量**：开箱即用，无需任何配置
- **数据离线存储**：所有用户数据保存在浏览器 localStorage，换设备需重新填写（后续可升级接入后端账号系统）

### 4.2 未来技术升级路径

| 升级方向 | 建议技术方案 |
|---------|-------------|
| **AI 推荐增强** | 接入 GPT-4 / Claude，将用户画像和想法框作为 Prompt，动态生成更精准的学习路线 |
| **后端与账号** | Node.js + MongoDB / Supabase，实现跨设备同步和多用户 |
| **自适应练习** | 接入 LLM API，根据用户错题记录动态生成薄弱点专项练习题 |
| **内容扩展** | 从硬编码的 3 个科目扩展到接入在线课程 API 或知识图谱 |
| **移动端适配** | 使用 React Native / Flutter 或 PWA 方案打包为 App |
